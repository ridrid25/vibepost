Supabase 0 / 5

Всё берётся в панели supabase.com в твоём проекте.

Supabase → твой проект → Settings → API → поле «Project URL». Выглядит как https://abcdefgh.supabase.co
Заполнится сам из Project URL. Это короткий код проекта (часть адреса до .supabase.co).
Settings → API → раздел «Project API keys» → ключ anon / public. Длинная строка, обычно начинается с eyJ или sb_publishable_
Settings → API → ключ service_role (нажми «Reveal», чтобы показать). Самый важный секрет — никому не пересылай.
Ты задавала его при создании проекта. Если забыла: Settings → Database → Reset database password (задай новый и вставь сюда).

Telegram 0 / 3

Тестовый бот и канал — по чеклисту из docs/04_SETUP.md.

Бот @BotFather → команда /newbot (или /mybots → твой бот → API Token). Формат: 1234567890:AAaa...
Перешли любое сообщение из канала боту @getidsbot — он покажет ID канала. Начинается с -100
Напиши боту @userinfobot — он ответит твоим ID (просто число). Сюда будут приходить уведомления об ошибках.

Защита вебхука 0 / 1

Случайная строка-пароль, которой защищается приём данных от Telegram. Придумывать не надо — нажми «Сгенерировать».
