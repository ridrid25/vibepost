# VibePost — пакет для передачи в Claude Code

## Что в папке

| Файл | Назначение |
|---|---|
| `CLAUDE.md` | Главная инструкция — Claude Code читает её автоматически |
| `docs/01_TZ.md` | Полное техническое задание |
| `docs/02_PLAN.md` | Этапы 0–6 с чекапами и правилами согласования |
| `docs/03_LOVABLE.md` | Готовые промпты для Lovable (фронтенд) |
| `docs/04_SETUP.md` | Чеклист подготовки (сделать ДО старта) |
| `.env.example` | Образец файла с секретами |
| `env-generator.html` | Страница для заполнения `.env` через браузер (открыть в Chrome) |
| `.gitignore` | Защита: не даёт закоммитить `.env` с секретами в git |

## Как запустить работу

1. Пройди чеклист `docs/04_SETUP.md`. Файл `.env` удобно собрать через `env-generator.html` (открой в Chrome, заполни поля, скачай). Файл должен называться ровно `.env` — с точкой в начале, без `.txt`. Если скачался как `env.txt` — переименуй (F2 → набери `.env` → Enter → «Да»).
2. Открой терминал в этой папке и запусти `claude`.
3. Вставь стартовый промпт:

```
Прочитай CLAUDE.md и все файлы в папке docs/ — это ТЗ и план проекта VibePost.

Правила работы: строго по этапам из docs/02_PLAN.md. В конце каждого этапа
останавливайся, показывай мне, что сделано и как проверить чекап, и жди моего
подтверждения «принято» — без него следующий этап не начинай. Все секреты бери
из .env, никогда не выводи их в чат и не коммить. Общайся со мной на русском,
объясняй простыми словами, я не программист.

Начинай с Этапа 0: инициализируй репозиторий и проект Supabase, создай и примени
все миграции по схеме из docs/01_TZ.md, включи RLS. В конце покажи мне, что
проверить в Supabase Dashboard для чекапа 0.
```

4. Дальше после каждого чекапа пиши Claude Code: «Чекап N принят, переходи к Этапу N+1».
5. Параллельно, начиная с Этапа 1, отдавай Lovable промпты из `docs/03_LOVABLE.md` — по одной странице за раз.
