# Подготовка перед стартом (чеклист для Татьяны)

Всё из этого списка нужно сделать ДО того, как Claude Code начнёт Этап 0.

## 1. Supabase
- [ ] Аккаунт на supabase.com, создать новый проект (регион — ближайший, например Frankfurt).
- [ ] Сохранить: **Project URL**, **anon key**, **service_role key** (Settings → API), **пароль БД** (задаётся при создании проекта), **Project Ref** (строка в URL проекта).
- [ ] В Dashboard → Database → Extensions включить `pg_cron` и `pg_net` (если Claude Code не сможет сделать это сам — он подскажет).

## 2. Telegram
- [ ] В @BotFather создать тестового бота → сохранить **токен**.
- [ ] Создать тестовый **канал**, добавить бота **администратором** с правом публикации сообщений.
- [ ] Узнать **Chat ID канала**: переслать любое сообщение из канала боту @getidsbot (ID вида `-100...`).
- [ ] Узнать **свой Telegram ID**: написать боту @userinfobot (для уведомлений об ошибках).

## 3. Локальное окружение
- [ ] Установлен Node.js LTS и Git.
- [ ] Установлен Claude Code, вход выполнен.
- [ ] В этой папке создать файл `.env` по образцу `.env.example` и заполнить значениями из пунктов 1–2. Файл `.env` никому не передавать и не коммитить.

## 4. Lovable
- [ ] Проект в Lovable создан (или будет создан на Этапе 1).
- [ ] После Этапа 0 подключить Lovable к ТОМУ ЖЕ проекту Supabase (интеграция Supabase в Lovable: понадобятся Project URL и anon key).

Когда все галочки стоят — открывай терминал в этой папке, запускай `claude` и вставляй стартовый промпт из README.md.
