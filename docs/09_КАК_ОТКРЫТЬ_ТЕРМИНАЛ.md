# Как открыть папку проекта и терминал

Для Татьяны. Без программистских слов.

---

## 1. Что такое папка проекта

Обычная папка на диске, в которой лежит всё наше: скрипты, документы,
настройки. По-человечески путь такой:

**Загрузки → Обучение → CLAUD → Отложенный постинг (рассылка) в ТГ**

### Как до неё дойти

1. Откройте **Проводник** — жёлтая папка на панели задач внизу экрана.
   Если её там нет, нажмите **Win + E** (Win — клавиша с окошком между Ctrl и Alt).
2. Слева в списке нажмите **Загрузки**.
3. Двойной щелчок по папке **Обучение**.
4. Двойной щелчок по **CLAUD**.
5. Двойной щелчок по **Отложенный постинг (рассылка) в ТГ**.

Вы внутри. Сверху в белой строке виден путь — это и есть адрес папки.

---

## 2. Что такое терминал

Чёрное окно, куда команды пишут словами, а не жмут кнопки.

Некоторые программы существуют только в таком виде — у них нет ни окошек, ни
кнопок. Программа `claude`, которая работает без Татьяны по расписанию, как раз
такая. Поэтому вход в неё делается там, а не в приложении.

**Приложение Claude и командный `claude` — разные программы с разными входами.**
Войти в одном не значит войти в другом. Именно поэтому 10 августа перезапуск
приложения не помог: вход обновился в приложении, а дежурный берёт учётные
данные из командного.

## 3. Как открыть терминал сразу в нужной папке

Это и есть то самое «открыть терминал в папке проекта» — чтобы окно смотрело
в нашу папку, а не куда попало. Иначе команды не найдут ни скриптов, ни настроек.

Три способа, любой подходит.

### Способ 1 — через адресную строку, самый простой

1. Дойдите до папки проекта, как в пункте 1.
2. Щёлкните **один раз** по белой строке с адресом наверху — путь выделится синим.
3. Наберите вместо него `cmd` и нажмите **Enter**.

Откроется чёрное окно, уже смотрящее в нашу папку.

### Способ 2 — правой кнопкой

1. Внутри папки щёлкните **правой** кнопкой по пустому месту.
2. Выберите **«Открыть в терминале»**.

В Windows 11 этот пункт иногда прячется за строкой «Показать дополнительные
параметры».

### Способ 3 — файлом с рабочего стола

На рабочем столе лежит **«Войти в Claude»**. Двойной щелчок — терминал
откроется сам, уже в нужной папке, и сам запустит вход. Набирать ничего не надо.

Это то же самое, что способы 1 и 2, только за неё.

---

## 4. Что набирать в терминале

Вход:

```
claude
```

Он спросит про вход — согласиться и войти тем же аккаунтом, что в приложении.
Появилось приглашение писать — вход готов, окно можно закрыть крестиком.

Проверить, что всё работает:

```
node scripts/самопроверка.mjs
```

Последняя строка скажет «Цепочка замкнута» — значит задания из бота
разбираются без неё.

## 5. Ловушка с рабочим столом

У Татьяны **два** рабочих стола:

| Папка | Видна на экране |
|---|---|
| `Users\rid-s\Desktop` | нет |
| `Users\rid-s\OneDrive\Desktop` | да, эту она видит |

Так бывает, когда включён OneDrive. Ярлыки надо класть во вторую, иначе они
есть на диске, но невидимы. 10 августа Claude на этом ошибся: положил файл
входа в первую, и Татьяна его не нашла.

Проверить, какая настоящая:

```
powershell -NoProfile -Command "[Environment]::GetFolderPath('Desktop')"
```
