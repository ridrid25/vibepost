- Хомяки: длинные `c` с именем приёма (MOUTH IN, LAZY SUSAN, BULLET TIME, OBJECT POV, OVERHEAD, DOLLY ZOOM, 3D ROTATION; 6–29 слов) не сыграны ни разу.
