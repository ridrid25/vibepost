# Дайджест по новостям с обложками — контракт VibePost ↔ Контент-завод

Статус на 16.10.2026: **построено и проверено, НЕ включено.** `news_config.digest_mode = 'single'` —
публикация идёт по-старому одним текстом. Включает только владелица.

## Сценарий
1. 08:30 МСК — подборка владелице (как раньше, `write-digest`, 3–5 пунктов «• …»).
2. Одно нажатие «✅ В канал» на всю подборку (`digest-button` → `digest_approve_items`).
   Пункты становятся отдельными новостями (`news_digest_items`, порядок 1..6, не больше шести,
   пустые слоты не заполняются). Повторное нажатие ничего не дублирует.
3. Сетка МСК: 09:30, 10:30, 11:30 (утро), 15:00, 16:00, 17:00 (день).
4. Позднее одобрение: утренняя №1 — по готовности её обложки (не раньше одобрения);
   №2 и №3 — не раньше часа от ФАКТИЧЕСКОЙ отправки предыдущей. Дневные — всегда свой слот.
5. Пересечение: если утренняя выходит позже 14:30 МСК — `blocked_overlap`, НЕ отправляется,
   владелице сообщение. Правило для этого случая владелица ещё не утвердила.
6. Нет обложки — пост ждёт; через 15 минут после слота одно сообщение владелице. Текст без
   обложки не уходит никогда.
7. Подпись под видео > 1024 знаков — `blocked_long_caption`, не обрезается.
8. Отправляет только VibePost (общий планировщик, `sendAnimation`: крутится без звука).

## Режимы `news_config.digest_mode`
- `single` — по-старому (сейчас);
- `items_dry` — сухой прогон: всё считается, обложки принимаются, постов НЕТ;
- `items` — боевой.

## Цепочка идентичностей
`news_digests.id` → `news_digest_items.id` (+ `item_order`) → `news_digest_publications.id`
(`cover_id`, `media_path`, `media_sha256`) → `posts.id` (уникален, `label = DIGEST:<digest>:<order>`)
→ `posts.tg_message_id` → `news_digest_publications.tg_message_id` (квитанция Telegram).

## Что делает Контент-завод (только это)
Edge Function `digest-covers`, заголовок `x-cf-key: <ключ>` (ключ — Vault `cf_digest_key`,
сервисный ключ Supabase заводу НЕ нужен и не выдаётся).

| Запрос | Ответ |
|---|---|
| `GET /functions/v1/digest-covers?vid=need` | `[{publication_id, digest_id, item_id, item_order, text, slot_at, dry_run}]` — новости, ждущие обложку |
| `POST /functions/v1/digest-covers?publication_id=…&cover_id=…&sha256=…`, тело — mp4 (`Content-Type: video/mp4`, 10 КБ–15 МБ) | `{result: "принято"}`; повтор той же обложки — `"повтор"`; после того как пост заведён — 409, обложку не меняем; sha256 не совпал — 422 |
| `GET /functions/v1/digest-covers?vid=sent` | только подтверждённые Telegram: `[{publication_id, digest_id, item_order, cover_id, tg_message_id, sent_at}]` — для галереи «В канале» |

Источник новостей — только `vid=need` (одобренная подборка VibePost), не радар завода.
Обложка: H.264 mp4 без звука, вертикаль/квадрат на усмотрение завода, ≤ 15 МБ.

2. Контент-завод должен реализовать клиента по контракту выше.
3. Владелица утверждает правило на случай пересечения утра с дневной сеткой (сейчас — стоп).
4. ~~Генератор 3–5 пунктов~~ — сделано 16.10: до шести.
5. Независимая проверка и боевой прогон в `items_dry`, потом `items` — по слову владелицы.
6. Известный остаточный риск Telegram: если ответ на sendAnimation потерян в сети, общий
