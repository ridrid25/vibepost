# Если что-то сломалось — кто и как чинит

## Правило первое
Каждое уведомление об ошибке теперь само содержит раздел «🔧 Что делать».
Сначала читаем его — в большинстве случаев этого достаточно.

## Таблица: симптом → кто чинит → как

| Симптом | Кто чинит | Что делать |
|---|---|---|
| ⚠️ «Ошибка отправки: chat not found» | **Вы, 2 минуты** | Настройки → удалить этот канал → привязать заново (проверить Chat ID / @имя) |
| ⚠️ «Бот потерял доступ / not enough rights / kicked» | **Вы, 2 минуты** | В Telegram: канал → Управление → Администраторы → добавить бота с правом «Публикация сообщений». Пост запланировать заново |
| ⚠️ «Токен бота недействителен / Unauthorized» | **Вы, 5 минут** | В Настройках добавить бота заново со свежим токеном из @BotFather |
| 🚨 «Постинг встал» (посты висят «Запланирован») | **Разработчик** | Открыть Claude Code в этой папке и написать: «сторож ругается, постинг встал». Клод найдёт причину по журналам |
| Кнопка/страница в приложении глючит | **Lovable** | Написать Клоду, что именно не так (скриншот) — он даст промпт-починку для Lovable |
| Приложение вообще не открывается, бот молчит несколько дней | **Supabase уснул** | Зайти на supabase.com → проект VibePost → кнопка Restore/Restart. Потом сказать Клоду — он всё проверит |
| Реакции не появляются в аналитике | **Никто — это норма** | Telegram доставляет реакции каналов с задержкой 1–5 минут. Ждём |
| Просмотры показывают «—» | **Никто — это норма** | Ограничение Telegram: ботам просмотры недоступны |

## Важно знать про бесплатный тариф Supabase
Проект живёт на бесплатном тарифе. Если приложением долго не пользоваться
(порядка недели), Supabase может «усыпить» проект — тогда встанет всё,
включая сторожа (он и не пикнет — некому). Профилактика: заходить
в приложение хотя бы раз в несколько дней. Если постинг станет боевым
и ежедневным — стоит перейти на платный тариф Supabase (Pro), там
проекты не засыпают.

## Как проверить, что сигнализация жива (раз в месяц)
1. В Telegram снять бота с администраторов тестового канала.
2. Запланировать туда пост на +2 минуты.
3. Дождаться ⚠️ в личку с подсказкой «Что делать».
4. Вернуть бота в администраторы.
